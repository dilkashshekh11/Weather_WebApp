# 🌦️ Weather Forecast Web App

A simple and responsive Weather Forecast Web App built with **HTML, CSS, and JavaScript**, using the **OpenWeatherMap API** to display real-time weather information for any city around the world.

## ✨ Features

- 🔍 **Search by City:** Find weather information for any city around the world.
- 🌡️ **Temperature:** View the current temperature in Celsius (°C).
- 🌤️ **Weather Conditions:** Display current weather descriptions with corresponding emojis.
- 🤗 **Feels Like:** Check the feels-like temperature.
- 💧 **Humidity:** View humidity levels as a percentage.
- 💨 **Wind Speed:** Get current wind speed in meters per second (m/s).
- ⚠️ **Error Handling:** Show helpful messages for invalid cities and API errors.
- 📱 **Responsive Design:** Enjoy a user-friendly interface across different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Structures the web application.
- **CSS3** – Styles the interface and layout.
- **JavaScript** – Handles user interactions and weather data.
- **OpenWeatherMap API** – Provides real-time weather information.

## 🚀 Getting Started

Follow these steps to run the project on your computer.

### 1. Clone the Repository

```bash
git clone https://github.com/dilkashshekh11/Weather_webApp_using_api_key.git
```

### 2. Open the Project

Open the downloaded project folder in Visual Studio Code.

### 3. Get an API Key

- Visit [OpenWeatherMap API](https://openweathermap.org/api).
- Create an account and generate an API key.

### 4. Configure the API Key

Open `script.js` and replace the placeholder with your API key:

```javascript
const API_KEY = "YOUR_OPENWEATHER_API_KEY";
```

### 5. Run the Application

Open `index.html` in your browser or use the **Live Server** extension in VS Code.

## 📸 How It Works

1. Enter a city name in the search field.
2. Click the search button.
3. The application sends a request to the OpenWeatherMap API.
4. The current weather information appears on the screen.
